ALGORITHMS DOCUMENTED
─────────────────────────────────────────────────────────────────────────────

1. Recommendation Scoring (PersonalizedDJ)
   - Genre matching: 30% weight
   - Artist matching: 25% weight
   - Energy level: 20% weight
   - Tempo matching: 15% weight
   - Mood matching: 10% weight
   - Discovery factor: Adjustable serendipity

2. Quality Scoring (DatasetManager)
   - Metadata completeness: 30% weight
   - Data consistency: 25% weight
   - Dataset size: 20% weight
   - Diversity (genres/artists): 15% weight
   - License permissiveness: 10% weight

3. Trust Score Calculation (BlockchainTrustNetwork)
   - Based on verification/report ratio
   - Formula: (verifications / total) × 0.8 + 0.1
   - Range: [0.1, 0.9] with sigmoid-like curve

4. Optimization Profile Selection (EdgeOptimizer)
   - Battery level < 30% → power_save profile
   - Cellular network → bandwidth_save profile
   - Bandwidth < 1 Mbps → bandwidth_save profile
   - High bandwidth + desktop → quality profile
   - Default → balanced profile
